## 📝 Descripción del Proyecto
Este proyecto consiste en el desarrollo de una **Aplicación de Página Única (SPA - Single Page Application)** construida enteramente con tecnologías web nativas (**Vanilla Architecture**: HTML5, CSS3 y JavaScript puro), sin el uso de frameworks externos. 

El objetivo principal es demostrar el manejo avanzado de la interactividad en entornos multimedia y modelos hipertextuales.

### Características Clave de la Fase 1:
* **Estructura HTML5 Semántica:** Maquetación limpia validada por la W3C utilizando etiquetas estructurales (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **Diseño CSS Responsivo (Mobile-First):** Interfaz totalmente adaptativa para dispositivos móviles y de escritorio mediante el uso combinado de **CSS Flexbox**, **CSS Grid** y *Media Queries*.
* **Navegación Dinámica SPA:** Implementación de un motor de navegación interna gestionado por JavaScript mediante la manipulación del DOM y eventos, evitando la recarga del navegador (`event.preventDefault()`).
* **Inclusión de Hipermedios e Interactividad:** Integración de componentes visuales (`<figure>` y `<img style="">`) y un panel informativo dinámico de tipo *toggle* controlado por eventos de usuario.

Instrucciones de Ejecución
Dado que el proyecto está desarrollado con tecnologías web estándar del lado del cliente, no requiere de compiladores, instaladores ni servidores complejos. Sigue estos pasos para ejecutarlo localmente:

Método 1: Ejecución Directa (Navegador)
Descarga o clona este repositorio en tu máquina local.

Asegúrate de estar en la rama fase-1.

Busca el archivo index.html en la raíz del proyecto.

Haz doble clic sobre él o arrástralo hacia la ventana de tu navegador web preferido (Google Chrome, Mozilla Firefox, Microsoft Edge, Brave, etc.).

Método 2: Usando Live Server (Recomendado en VS Code)
Abre la carpeta del proyecto en Visual Studio Code.

Si no la tienes, instala la extensión Live Server de Ritwick Dey.

Abre el archivo index.html.

Haz clic en el botón "Go Live" ubicado en la barra de estado inferior de VS Code. Esto levantará un servidor local automático (normalmente en http://127.0.0.1:5500) y refrescará la página con cada cambio.
